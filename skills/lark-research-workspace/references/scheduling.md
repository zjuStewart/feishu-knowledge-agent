# 每日同步

使用当前宿主的自动化能力创建或更新同一个任务，默认每日一次。先完成一次手动同步验收；不要另建重复任务。没有调度工具时说明只能手动触发。

可采用以下任务内容，把路径替换为本人的安装位置与配置：

> 读取主 Skill 的 SKILL.md，遵守当前工作区规则。只运行一次 workspace.py --config PERSONAL_PROFILE daily-sync，检查返回值及 state/daily-status.json。按稳定ID跟踪目录增删、改名、移动和可访问性；保留历史缓存，但不把失效资料作为当前背景。出现 needs_summary 时，仅为列出的完整正文生成版本绑定摘要，再执行 set-summary、sync-context、receive-cloud，不重跑整个 daily-sync。根节点不可见时停用旧背景，提示恢复访问或指定新根。认证失败不自动重新授权，不读取模型密钥。永不在定时任务执行归档 execute，也不向他人发送消息。无实质变化保持安静；变化、失败或需要用户处理时才简短通知。

本地同步需要设备在线；飞书事件工作独立配置。默认使用飞书内置模型，不需要 OpenAI API Key。未来用户要求外部模型时，先确定部署位置和接口，再让用户在专用密钥界面亲自设置，Agent 不读取设置值。
